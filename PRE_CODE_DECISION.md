## Two composition directions considered

1. Warm domestic reassurance: light palette and service cards. Rejected because it would resemble a generic local-trade template and flatten the technical credibility gap.
2. Replaceable service homepage: graphite substrate, a compact anchored header, one real-work hero, distinct supporting work imagery, expanded service range, dated public work records, verified external profiles and direct contact routes. Selected because it can function as the business's finished static homepage rather than a poster-like concept.

## Anti-template decisions

No invented imagery, testimonials, numbers, service guarantees, fake dashboard, generic building-maintenance copy, form, or decorative social links. Facebook/Instagram may be added only after a business-owned account URL is verified; generic social-platform homepages are excluded. B-class customer-profile images remain local-concept-only with source/hash evidence in the ledger. Palette: Void #101314, Zinc #1A2021, Ash #E9ECE7, Ember #D6603D. One accent. Radius system: 14px panels and pill buttons only.

## First-pass engineering gate

Static HTML/CSS only. Primary CTA uses `tel:`; secondary CTA uses `mailto:`. No scripts required for data capture. Motion is CSS entrance/hover only and disabled under reduced motion.
